# v0.1.0 Production Readiness Release

Hardening, security patches, database lifecycle management, and privacy compliance:
- Epistemic classifier with deterministic taxonomy and conflicting-signal fallback
- Versioned vendor IP ranges and automated monthly refresh workflow
- Opt-in behavioral signals, GPC enforcement, and GDPR/ePrivacy documentation
- Database indexing, hashed API keys, admin authentication, and retention lifecycle pruning
- Multi-runtime middleware with fail-open resilience, bounded retries, and timeouts
- Structured JSON logging with request IDs and zero PII leakage
- Prometheus metrics export at /api/metrics
- Production Dockerfile (Node 22 LTS, non-root user, standalone Next.js) and docker-compose with PostgreSQL and Redis
